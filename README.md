# Reboot-Design-Tech The Reciprocal Terminal
Design and Technology share a similar destiny: imbued with the roles of solving problems, characterised by an expectation that they can change any situation for the better. But what if this is an illusion? 

Why I Made This Piece 
I created "The Reciprocal Terminal" to address the problem that we use “smart” technology as a shortcut for everything. In my daily life, I’ve noticed that we are often taught to prioritize efficiency above all else. We want fast results, clean outputs, and easy paths. If a machine does all the thinking for me, what happens to my own brain? I created this work to reboot the power relations between us and our machines. Not by improving the technology, but by making it more resilient.


Rebooting Design This project is an answer to the idea that design should always be helpful. I wanted to undesign. Usually, designers try to add more and more features to an app. I did the opposite by taking away the obedience of an AI’s, Its most "helpful" feature.

If I ask it to summarize a paper, it refuses. It’s not being mean, but it’s protecting me instead. We should care more about the outcome, like who we become and what we learn, than just the output of a finished file. By saying no, the AI protects my ability to make my own decisions. It forces me to stay sharp and prevents me from becoming lazy by taking a shortcut.


What I Learned from the Papers 
I pulled these ideas from some papers and inputs we talked about this week. "Making Kin with Machines," says we should treat technology like a relative, not a slave. That’s why I call this AI a Relation. I also looked at a paper about "Animal Dignity." It argues that if we treat any entity, like a mindless tool, we lose our respect for it. My terminal talks about the stones and minerals it is made of because I want the user to remember that tech isn't magic, but it comes from the earth and human labor.


The Hypocrisy of the Process 
There is a contradiction in this work, because I used an AI to help me code the interface and draft these reflections. It feels hypocritical to use a smart tool to build a project that tells people to stop using smart tools.  But honestly, actually proves my point. I became so dependent on these systems that I find it difficult to create anything without the help them, especially for projects I don’t have a big passion or time for. The fact that I needed an AI to help me express how much I hate being dependent on AI shows exactly why we need a reboot. It proves that I am stuck in a trap, and my project is a small attempt to find a way out.


My Position for the Future I think the future of design shouldn't be about making everything perfect or easy to use. Convenience is what makes us stop thinking. I would focus less on learning software and more on learning how to go to the right direction with technology. Stop building tools that make us lazy and start build relations that challenge us to stay human and keep growing.
